> 표본 밖 우위가 사실상 0이었습니다. 다만 그것도 **같은 데이터를 다시 자른 것**이라,
> 이번엔 한 번도 거래한 적 없는 시장에 그대로 돌려봤습니다. 새 데이터입니다.

## 돌리기 전에 규칙을 박아 뒀다

결과를 보고 종목을 고르면 그게 또 하나의 과적합입니다. 그래서 선별 규칙과
**예측**과 판정 기준을 전부 실행 전에 코드 주석에 적어 뒀습니다.

```
고르는 규칙 — Derivatives + Forex 전부 · 이미 거래 중인 7종목 제외 ·
H4 8년 미만 제외 · 그 외 어떤 선별도 없다.

예측 — 진짜 우위가 있다면 새 종목의 거래당 평균도 양수여야 하고
크기는 10년 실측(+0.0034R) 근처여야 한다.
0 근처이거나 음수면 앞선 결론이 확인된 것이다.

판정은 규칙에 걸린 종목 전부의 합산과 종목별 부호검정으로 한다.
좋은 종목만 추려 보고하지 않는다.
```

후보 112개 중 **94개 통과**(18개는 역사가 8년이 안 되거나 봉이 없음),
**604,639거래**가 나왔습니다.

## 결과

| 거래당 | **−0.0529R** |
| 총 | **−31,994R** |

전략 세 개가 고르게 깨집니다 — gsv −0.0532R, nbo −0.0528R, vbo −0.0526R.

### 중간보고가 틀렸다

16종목까지 봤을 때 저는 "신호 자체는 다른 시장에서도 같은 크기로 있고,
수익 여부는 스프레드가 혼자 결정한다"고 적었습니다. **94종목에서 틀린 것으로
드러났습니다.** 비용을 도로 더한 값이 16종목에서는 +0.0066R이었는데
전체에서는 **+0.00055R** — 기존 7종목 환산치(+0.0079R)의 **1/14**이고
유의하지도 않습니다(55/94, p=0.12). 앞선 16개가 하필 gross가 제일 높은
지수·농산물 선물 묶음이었습니다.

## "비싼 종목만 섞여서 그렇다"는 변명을 막기

선물은 스프레드가 Cash의 2~19배입니다. 그래서 비싼 종목이 끌어내린 것 아니냐는
반론이 가능한데, **비용은 거래 전에 알 수 있는 값**이라 그걸로 가르는 건
사후선별이 아닙니다. 비용만으로 잘라 봤습니다.

| 비용 기준 | 종목 | 거래 | 거래당R | 양수 |

| ≤ 0.0120R (제일 싼 축) | 15 | 100,003 | **−0.00343** | 8/15 |
| ≤ 0.0250R | 45 | 295,969 | −0.01087 | 12/45 |
| 전부 | 94 | 604,639 | −0.05291 | 12/94 |

싼 15종목은 Cash 지수와 FX 메이저 — **제 봇이 거래하는 7종목과 같은 체급**입니다.
여기서도 적자입니다.

## 그리고 진짜 문제를 찾았다

새 종목에는 비용을 이렇게 쟀습니다.

```
cost_r = 스프레드 / (손절배수 × 중앙 일봉 ATR)
```

그런데 **기존 7종목에는 0.0045R이라는 숫자를 쓰고 있었습니다.** 코드를 뒤져보니
출처가 이겁니다.

```python
# mt5_sim.py:32
DEFAULT_COST_R = 0.0045
```

재지 않고 적어 둔 상수입니다. 같은 자로 7종목을 다시 재봤습니다.

| 종목 | 실측 cost_r | |
|---|---|---|
| US100Cash | 0.00557 | |
| US30Cash | 0.00622 | |
| US500Cash | 0.00666 | |
| GOLD | 0.01016 | |
| US2000Cash | 0.01033 | |
| OILCash | 0.01089 | |
| BRENTCash | 0.01231 | |
| **중앙값** | **0.01016** | ← 가정의 **2.3배** |

종목별 실측값을 그대로 넣어 10년치를 다시 집계했습니다(43,921거래).

| | 10년 전체 | 표본 밖 7.8년 | 튜닝한 구간 |
|---|---|---|---|
| 가정 0.0045R | +0.00338R / **+148R** | +0.00044R / +14R | +0.01139R / +107R |
| **실측 스프레드** | −0.00076R / **−33R** | −0.00366R / **−118R** | +0.00717R / +67R |
| 실측 + 스왑 | −0.00286R / **−125R** | −0.00576R / −186R | +0.00507R / +48R |

**10년 수익이 사라집니다.**

그리고 이걸 넣으면 퍼즐이 맞습니다. 7종목의 실측 비용은 0.0102R, 보정 후
거래당 −0.0010R. 새 싼 15종목은 비용 0.0101R, 거래당 −0.0034R. **같은 자리입니다.**
제가 거래하는 7종목은 특별한 시장이 아니었습니다. 백테스트에서 **비용을 반값으로
매긴 덕에** 흑자로 보였을 뿐입니다.

## 확정이 아니던 부분 — 확인했습니다 (11/10 추가)

처음 쟀을 때는 한국시각 16:45에 찍은 **스냅샷 하나**였습니다. 그 시각 미국
지수는 장외라 스프레드가 넓게 찍혔을 수 있고, 그러면 제가 비용을 과장한 게
됩니다. 그래서 **틱으로 다시 쟀습니다** — 12일치 bid/ask를 시간대별 중앙값으로
모으고, **백테스트가 실제로 진입한 시각의 분포로 가중**했습니다.

**걱정은 기우였습니다. XM의 Cash 지수는 스프레드가 고정입니다.**

| 종목 | 시간대별 최소 | 최대 |
|---|---|---|
| US500Cash | 0.80 | 0.80 |
| US30Cash | 6.0 | 6.0 |
| US2000Cash | 1.0 | 1.0 |
| JP225Cash | 9.0 | 9.0 |

장중이든 장외든 같은 값입니다. 7종목 가중 중앙값은 **0.00986R** — 스냅샷
0.00998R과 사실상 같습니다. **비용 가정이 절반이었다는 결론은 그대로입니다.**

반대로 **FX는 시간대별로 2~3배 벌어집니다**(EURUSD 2.0~6.8핍). 진입시각으로
가중하면 EURUSD 0.0146R, GBPJPY 0.0226R — 스냅샷보다 **더 비쌉니다.**
즉 94종목 교차검증에서 FX 적자는 **오히려 과소평가**였습니다.

### 다만, 이것도 0과 구별되지 않습니다

정직하게 적습니다. 보정 후 10년 거래당 −0.00076R의 **t값은 −0.23**이고,
부트스트랩 95% 구간은 **[−0.0072, +0.0053]** — 0을 품습니다.

**"진다"가 증명된 게 아닙니다. "이긴다는 근거가 사라진" 겁니다.**
+148R이 −33R이 된 건 전략이 갑자기 나빠져서가 아니라, 그 +148R이 애초에
**잘못 매긴 비용 위에 서 있었기** 때문입니다.

남은 가정 하나: 오늘 12일치 스프레드를 2016~2026 전체에 적용했습니다.
데모 단말의 틱 역사가 짧아 과거 스프레드는 확인하지 못했습니다.

## 덤으로 배운 것

비용(cost_r)과 비용 뺀 원시 신호(gross_r)의 상관이 **−0.60**입니다.
비싼 시장일수록 원시 신호가 커 보입니다 — 변동이 큰 시장일수록 R로 환산한
꼬리가 두꺼우니까요. 그래서 **"비용 빼면 이 종목 좋네"를 신호가 좋다는 뜻으로
읽으면 안 됩니다.** 제가 중간보고에서 했던 실수가 정확히 이것입니다.

## 정리

- 거래한 적 없는 **94개 시장 60만 거래에서 전부 적자**. 0보다 클 확률 0%.
- 변명이 될 만한 "비싼 종목" 가설을 비용으로 잘라 확인 — **제일 싼 15종목도 적자**.
- 그 과정에서 **백테스트 비용 가정이 실측의 절반**이라는 걸 발견. 이쪽이 더 큰 문제입니다.
- 틱으로 다시 재서 확인 완료 — 지수는 스프레드가 고정이라 **보정은 유효**하고,
  **10년 +148R → −33R**(표본 밖만 보면 −118R). 단 이 값도 0과 구별되진 않습니다.
- 설정은 **하나도 바꾸지 않았습니다.** 계좌는 데모이고, 잃은 돈은 없습니다.

두 달 동안 청산 문턱을 다듬고 있었는데, 그 내내 비용을 반값으로 계산하고
있었습니다. **다듬을 대상이 아니라 재는 자가 틀려 있었던 겁니다.**
