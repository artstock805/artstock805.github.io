## 1. caveman — 에이전트 응답을 "원시인 말투"로 압축

에이전트의 답변을 기술적 정확성은 유지하면서 **간결한 원시인식 말투**로 압축해 주는 스킬/플러그인입니다. 코드·명령어·에러 정보는 그대로 두고 군더더기만 줄여 **출력 토큰을 약 65% 절감**합니다. Claude Code, Gemini, Cursor, Cline 등 30여 개 에이전트에서 사용 가능해요.

- 언어/라이선스: JavaScript(Node.js) · MIT
- 🔗 <https://github.com/juliusbrussee/caveman>

## 2. manim_skill — 3Blue1Brown 스타일 수학 애니메이션

수학 시각화 라이브러리 **Manim**으로 3Blue1Brown 풍의 애니메이션을 만들 수 있게 도와주는 에이전트 스킬입니다. 서로 호환되지 않는 **Manim Community Edition**과 **ManimGL** 양쪽의 검증된 코드 예시·베스트 프랙티스를 한데 모아, AI 코딩 에이전트가 바로 활용할 수 있게 정리해 둔 것이 핵심입니다.

- 언어: Python
- 🔗 <https://github.com/adithya-s-k/manim_skill>

## 3. anthropics/skills — frontend-design 스킬

Anthropic 공식 스킬 저장소의 **프론트엔드 디자인** 스킬입니다. UI를 만들거나 개선할 때 **의도적이고 개성 있는 시각 디자인**을 하도록 안내합니다. 팔레트·타이포그래피·레이아웃에서 템플릿 같은 기본값을 피하고, 프로젝트마다 고유하고 과감한 미적 선택을 하도록 유도하는 가이드예요.

- 🔗 <https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md>
