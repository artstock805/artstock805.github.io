## 📌 프롬프트 엔지니어링이란?

프롬프트 엔지니어링은 **AI에게 정확하고 유용한 답변을 받기 위해 질문을 효과적으로 설계하는 기술**입니다.

### 왜 중요할까요?

같은 AI라도 질문을 어떻게 하느냐에 따라 답변의 질이 천차만별입니다. 좋은 프롬프트는 시간을 절약하고 학습 효율을 10배 높여줍니다.

**❌ 나쁜 프롬프트 예시**

```text
pandas 알려줘
```

**✅ 좋은 프롬프트 예시**

```text
데이터 분석 입문자입니다. pandas로 CSV 파일을 읽고
기초 통계량(평균, 중앙값, 표준편차)을 확인하는 방법을
코드 예시와 함께 설명해주세요. 각 단계마다 주석으로
설명을 달아주시면 감사하겠습니다.
```

**차이점**

- 나의 수준 명시 (입문자)
- 구체적인 작업 내용 (CSV 읽기, 통계량 확인)
- 원하는 결과물 형태 (코드 예시 + 주석)

### 2단계 — 구체적인 목표 제시하기

- ✅ 구체적인 목표:


### 3단계 — 데이터 정보 공유하기

분석할 데이터에 대한 정보를 제공하세요.

- 데이터 형식 (CSV, Excel, JSON 등)

- 특이사항 (결측치, 이상치 등)

```text
다음과 같은 구조의 CSV 파일이 있습니다.
```

| 컬럼명 | 데이터 타입 | 설명 |
|--------|------------|------|
| customer_id | 정수 | 고객 ID |
| purchase_date | 날짜 | 구매일 (YYYY-MM-DD) |
| amount | 실수 | 구매금액 |
| category | 문자열 | 상품 카테고리 |

총 10,000개 행이며, `amount` 컬럼에 약 5%의 결측치가 있습니다.

### 5단계 — 제약사항 알려주기

한계나 제한사항이 있다면 미리 알려주세요.

```text
- scikit-learn 라이브러리는 아직 배우지 않아서 사용할 수 없습니다.
```

## 💡 단계별 질문 기법 (너무 복잡할 때)

## 🎓 학습 효율을 높이는 고급 프롬프트 기법

- **기법 1 — "나에게 가르쳐줘"**: ① 5세 아이에게 설명하듯 ② 일상 비유 ③ 기술적 정의 ④ 코드 예시 ⑤ 자주 하는 실수, 이렇게 5단계로 설명 요청
- **기법 2 — "반대로 질문받기"**: 개념 관련 질문 3개를 내달라고 하고, 내 답변으로 이해도를 평가받기
- **기법 3 — "실무 연결"**: 이 기술이 실무에서 ① 어떤 상황에 ② 어떤 비즈니스 문제 해결에 ③ 실제 사례 2~3가지로 쓰이는지 질문
- **기법 4 — "비교 학습"**: A 방법과 B 방법의 특징·장단점·사용 상황·코드 예시를 비교 요청 (예: `merge()` vs `join()`)

## 🚨 자주 하는 실수와 해결법

| 실수 | ❌ 나쁜 예 | ✅ 좋은 예 |
|------|-----------|-----------|
| 너무 짧게 질문 | "pandas 에러" | 에러 메시지 전체 + 코드 + 시도한 것 첨부 |
| 맥락 없이 코드만 | `df.groupby('A')['B'].sum()` | 데이터 구조 + 원하는 결과 + 현재 문제 설명 |
| 한 번에 너무 많이 | "pandas 전체 기능 다 알려줘" | "핵심 기능 TOP 10을 우선순위대로" |

| "알아서 해줘" | "데이터 분석해줘" | 목적·데이터·원하는 분석 3가지를 구체적으로 |
